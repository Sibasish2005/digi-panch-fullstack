Challenges & Solutions

State Synchronization

Keeping user state synced between Clerk (auth provider) and the FastAPI database.

Solution: Custom dependency `get_current_user` that intercepts the JWT, verifies it via public keys, and upserts the user to PostgreSQL transparently on every request.

AI Hallucinations

Gemini providing inaccurate answers about Panchayat laws.

Solution: Implemented RAG pipeline with `pgvector` to strictly inject contextual knowledge chunks into the Gemini prompt.
